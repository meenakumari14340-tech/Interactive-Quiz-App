# Quiz App

This project is an interactive Quiz App developed using HTML, CSS, and JavaScript. It allows users to answer multiple-choice questions, track their scores, and view the correct answers when they submit an incorrect answer or when the timer runs out. The application includes a countdown timer, answer validation, score calculation, and a responsive design for mobile devices while maintaining the original desktop layout.

**Technologies Used:** HTML, CSS, JavaScript

**Key Features:**
- Interactive multiple-choice questions
- Countdown timer for each question
- Automatic display of correct answers
- Instant answer feedback
- Score calculation and result screen
- Responsive mobile-friendly interface
- Clean and user-friendly design
